## Supplementary Figure S9: Zoomed adoption dynamics

### Script

`Figure9_SI_Adoption.m

### Description

This script generates the zoomed-in visualization of adoption trajectories
reported in Supplementary Figure S9.

The figure highlights the convergence behavior of overall adoption
under different levels of intergroup interaction.

The scenarios considered are:

- I = 0
- I = 0.14
- I = 0.37
- I = 0.5

### Output

The script generates:

- Zoomed adoption trajectories over the final simulation period
  (t = 100 to 120).

### Running the code

Run:
Figure9_SI_Adoption.m
