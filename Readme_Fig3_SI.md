## Supplementary Figure S3: Population size sensitivity analysis

### Script

`Figure3_SI_PopulationSize.m`

### Description

This script reproduces the sensitivity analysis reported in Supplementary Figure S3.

The analysis investigates how the total population size affects innovation adoption and disparity outcomes.

The population size is varied from:

- n = 8,000
- n = 40,000

Two scenarios are examined:

1. Intergroup interaction sensitivity:
   - Different levels of interaction/homophily

2. Learning-rate sensitivity:
   - E = 0.16
   - E = 0.18
   - E = 0.20

### Outputs

The script generates plots showing:

- equilibrium disparity as a function of population size;
- overall adoption as a function of population size.

### Running the code

Run:
Figure3_SI_PopulationSize.m
