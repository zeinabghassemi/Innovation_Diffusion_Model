## Figure 3: Seeding policy analysis

### Script

`Figure3_seeding_policy_heatmaps.m`

### Description

This script reproduces the heatmaps presented in Figure 3 of the manuscript.

The analysis compares three seeding policies:

- S1
- S2
- S3

under different levels of:

- intergroup interaction (`I`)
- technology learning rate (`E`)

The script visualizes two outcomes:

1. Overall adoption level
2. Equilibrium disparity between communities

### Outputs

The script generates four heatmaps:

- Adoption vs intergroup interaction
- Equilibrium disparity vs intergroup interaction
- Adoption vs learning rate
- Equilibrium disparity vs learning rate

### Running the code

Run: 
Figure3_SeedingHeatmap.m
