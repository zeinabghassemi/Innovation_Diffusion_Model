## Supplementary Figure S5: Parameter sensitivity analysis

### Script

Figure5_SI_InteractionHeatmap.m

### Description

This script reproduces the parameter sensitivity analysis presented in Supplementary Figure S5.

The analysis evaluates the robustness of adoption and disparity outcomes under different combinations of:

- innovativeness rate (`p`);
- refusal rate (`s`);
- intergroup interaction levels (`I`).

### Outputs

The script generates heatmaps showing:

- equilibrium disparity across parameter combinations;
- equilibrium adoption across parameter combinations.

The results are evaluated for different levels of intergroup interaction.

### Running the code

Run:
Figure5_SI_InteractionHeatmap.m
