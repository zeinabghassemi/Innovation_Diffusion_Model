## Supplementary Figure S8: Learning rate, price, and benefit sensitivity analysis

### Script

Figure8_SI_LearningRateBenefitHeatmap.m

### Description

This script reproduces the sensitivity analysis presented in Supplementary Figure S8.

The analysis investigates how innovation characteristics affect equilibrium adoption and disparity outcomes under different technology learning rates.

The explored parameters are:

- Learning rate (`E`)
- Initial innovation price (`rho_0`)
- Adoption benefit (`q`)

The learning-rate scenarios considered are:

- E = 0.16
- E = 0.18
- E = 0.20

### Outputs

The script generates heatmaps showing:

- equilibrium disparity;
- equilibrium adoption;

for combinations of initial price and adoption benefit.

### Running the code

Run:
Figure8_SI_LearningRateBenefitHeatmap.m
