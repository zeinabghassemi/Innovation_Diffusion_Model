## Supplementary Figure S7: Initial price and benefit sensitivity analysis

### Script

Figure7_SI_InitialPriceHeatmap.m

### Description

This script reproduces the sensitivity analysis reported in Supplementary Figure S7.

The analysis investigates how innovation characteristics influence adoption and disparity outcomes.

The explored parameters are:

- Initial innovation price (`rho_0`)
- Adoption benefit (`q`)
- Intergroup interaction level (`I`)

The analysis considers three interaction scenarios:

- I = 0.5
- I = 0.25
- I = 0

### Outputs

The script generates heatmaps showing:

- equilibrium disparity;
- equilibrium adoption;

under different combinations of initial price and adoption benefit.

### Running the code

Run:
Figure7_SI_InitialPriceHeatmap.m
