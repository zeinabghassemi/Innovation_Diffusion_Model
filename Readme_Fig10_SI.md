## Supplementary Figure S10: Learning rate sensitivity analysis

### Script

Figure10_SI_LearningRate_Sensitivity.m

### Description

This script reproduces the learning-rate sensitivity analysis reported in Supplementary Figure S10.

The analysis investigates how changes in the technology learning rate influence innovation adoption and inequality outcomes.

The simulations consider:

- low learning rate: E = 0.16
- moderate learning rate: E = 0.18
- high learning rate: E = 0.20

while maintaining the baseline intergroup interaction level.

### Outputs

The script generates:

- overall adoption trajectories;
- transient disparity trajectories;
- cumulative disparity across learning rates.

### Running the code

Run:
Figure10_SI_LearningRate_Sensitivity
