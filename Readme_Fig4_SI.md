## Supplementary Figure S4: Community size ratio sensitivity analysis

### Script

`Figure4_SI_CommunitiyRatioSize.m`

### Description

This script reproduces the sensitivity analysis presented in Supplementary Figure S4.

The analysis investigates how the relative size of the high-income and low-income communities affects innovation adoption and disparity outcomes.

The community size ratio is varied while examining two model dimensions:

1. Intergroup interaction/homophily effects:
   - h = 1
   - h = 0.875
   - h = 0.8
   - h = 0.5

2. Learning-rate effects:
   - E = 0.16
   - E = 0.18
   - E = 0.20

### Outputs

The script generates plots showing:

- equilibrium disparity as a function of community size ratio;
- overall adoption as a function of community size ratio.

### Running the code

Run:
Figure4_SI_CommunitiyRatioSize.m
