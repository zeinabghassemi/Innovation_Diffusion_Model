## Supplementary Figure S6: Learning-rate sensitivity analysis

### Script

Figure6_SI_LearningRateHeatmap.m

### Description

This script reproduces the sensitivity analysis reported in Supplementary Figure S6.

The analysis evaluates how adoption and disparity outcomes change under different combinations of:

- innovativeness rate (`p`);
- refusal rate (`s`);
- technology learning rate (`E`).

The learning-rate scenarios considered are:

- E = 0.16
- E = 0.18
- E = 0.20

### Outputs

The script generates heatmaps showing:

- equilibrium disparity;
- equilibrium adoption;

for each learning-rate scenario.

### Running the code

Run:
Figure6_SI_LearningRateHeatmap.m
